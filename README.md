# Luotokoti — sivustoprototyyppi (julkaisupeili)

Tämä repo on **vain julkaisua varten**. Se sisältää sen mitä selain lataa —
HTML:n, tyylit, skriptit ja kuvat — eikä mitään muuta.

**Kanoninen lähde on `generoi/luotokoti-prototyyppi`.** Siellä ovat
projektin dokumentaatio (avoimet kysymykset, tarkastukset, kuvatarpeet,
agenttibrief), generointityökalut ja koko versiohistoria. Älä tee muutoksia
tähän repoon: ne katoavat seuraavassa julkaisussa.

Tämä peili on olemassa siksi, että GitHub Pagesin kytkeminen vaatii
admin-oikeudet repoon, eikä niitä ollut. Kun oikeudet järjestyvät,
julkaisu siirtyy kanoniseen repoon ja tämä poistetaan.

## Julkaisu

Peili päivitetään kanonisesta reposta komennolla `bash tyokalut/julkaise.sh`.
Historiaa ei tuoda mukana, koska dokumentit eivät kuulu julkiseen repoon.

## Prototyypistä

Prototyyppi on päätöksenteon väline, ei valmis sivusto. Puuttuva sisältö
näkyy sivuilla merkittynä aukkona, ja osa luvuista on kuvitteellisia —
sivusto kertoo sen itse footerissa. Kaikki sivut ovat `noindex, nofollow`.
